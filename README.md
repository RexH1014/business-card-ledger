# Business Card Ledger

手機和電腦都可以打開：[https://rexh1014.github.io/business-card-ledger/](https://rexh1014.github.io/business-card-ledger/)

`127.0.0.1` 只在你自己的電腦有效，不能分享給朋友。
左邊「加入名片」用三個分頁切換：新名片、用鏡頭掃描、掃描名片。鏡頭只填入新名片，不會直接加入名單。上傳 PDF 或相片仍會直接寫進名單。

「儲存檔案」在名單的「匯出 Excel」右邊。按了之後，電腦和手機打開這份名片錄，都會看到各裝置已經儲存的名單。

刪除一張或清空名單之後，這個分頁還開著就可以按還原。關掉分頁就不能還原。
